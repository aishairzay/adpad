# Ad Pad visual direction

An original streetwear and independent magazine direction: near-black, warm ivory, acid lime and cobalt; oversized Anton display type, Archivo text; full-bleed campaign photography, sharp image cards and compact, useful metadata. Award-site reference: [Finely Crafted, Awwwards Site of the Day](https://www.awwwards.com/sites/finely-crafted). No third-party layout or source code was copied.

The initial marketplace and creator cards are clearly labeled concepts and cannot be booked. Their names, prices and availability are illustrative. Event artwork on the Events page comes from the corresponding official event sources, linked in `events-sources.md`.
